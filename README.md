# 🥑 AtmoSync: Micro-Climate Arbitrage Analytics

[![dbt Core](https://img.shields.io/badge/dbt-v1.12.0-orange.svg)](https://www.getdbt.com/)
[![Snowflake](https://img.shields.io/badge/Snowflake-Data_Warehouse-blue.svg)](https://www.snowflake.com/)
[![Kafka](https://img.shields.io/badge/Apache_Kafka-Data_Streaming-black.svg)](https://kafka.apache.org/)

**AtmoSync** is a real-time analytics and data engineering platform designed to optimize agricultural cold-chain logistics. By processing continuous hyper-local container telemetry streams (temperature, humidity, and vibration), AtmoSync models exponential avocado spoilage decay rates, projects cargo arrival quality across candidate market destinations, and alerts commodities traders to high-payout rerouting opportunities (**Spoilage Arbitrage**) before produce degrades below market grade.

---

## 🌟 Key Features

* **High-Throughput IoT Ingestion**: Processes 50,000+ IoT container telemetry stream events generated by simulated shipping containers.
* **Resilient JSON Staging**: Employs `TRY_PARSE_JSON` parsing, UTC timestamp standardization (`TIMESTAMP_NTZ`), null fallback defaults, and dual-schema key coalescing (`sequence_id`/`event_id` and `sensor_id`/`container_id`).
* **Micro-Climate Spoilage Decay Math**: Calculates mathematical decay multipliers ($M_{\text{decay}}$) and cumulative cargo quality degradation ($Q_t \in [0.0, 1.0]$) in Snowflake SQL.
* **Spoilage Arbitrage Valuation**: Maps projected arrival quality to commodity price tiers (Premium, Standard, Substandard) and calculates net financial arbitrage values vs. the default New York baseline.
* **Automated Trader Rerouting Alerts**: Triggers real-time alerts for reroute opportunities yielding $\ge \$50.00$ net profit improvement.
* **Pre-Computed Marts & BI Reporting Views**: Materializes physical tables and optimized reporting views (`rpt_container_health_summary` and `rpt_arbitrage_opportunities`) for Power BI / Superset dashboards.
* **High Quality Standards**: Validated against **40 automated data assertions** with 100% test pass rate.

## 🧮 Mathematical Model

### 1. Environmental Spoilage Decay Multiplier
$$M_{\text{decay}} = e^{k_T(T - T_{\text{opt}})} \cdot e^{k_H(H - H_{\text{opt}})}$$
* $T_{\text{opt}} = 5.0^\circ\text{C}$, $k_T = 0.08$
* $H_{\text{opt}} = 85.0\%$, $k_H = 0.02$

### 2. Cumulative Quality Index
$$Q_t = \max\left(0.0, \, Q_{t-1} - \text{base\_decay} \cdot M_{\text{decay}} \cdot \Delta t\right)$$
Bounded strictly to $[0.0, 1.0]$.

### 3. Spoilage Arbitrage Margin
$$\text{Spoilage Arbitrage} = \text{Cargo Value}_{\text{Candidate Market}} - \text{Baseline Value}_{\text{New York}} - \text{Rerouting Cost}$$

## 🚀 Quickstart & Setup

### 1. Installation & Virtual Environment
```bash
# Clone the repository
git clone https://github.com/sree-blip/AtmoSync-Micro-Climate-Arbitrage-Analytics.git
cd AtmoSync-Micro-Climate-Arbitrage-Analytics

# Create and activate virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .\.venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### 2. Run dbt Seeds & Models
```bash
# Seed reference candidate market prices
dbt seed

# Build staging and marts models
dbt run

# Run full-refresh build
dbt run --full-refresh
```

### 3. Data Quality Testing & Documentation
```bash
# Execute all 40 automated data assertions
dbt test

# Generate interactive documentation and DAG lineage graph
dbt docs generate
dbt docs serve
```
